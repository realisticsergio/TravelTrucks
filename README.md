# TravelTrucks

TravelTrucks is a camper rental web application built with Next.js and TypeScript. Users can browse campers, filter the catalog, view detailed camper information and submit booking requests.

## Features

- Camper catalog loaded from the Campers API
- Backend filtering by location, form, engine and transmission
- Infinite pagination with Load More
- Camper details and image gallery
- User reviews with five-star ratings
- Booking form with success notification
- Light and dark themes
- Responsive layout

## Technologies

- Next.js
- TypeScript
- React
- TanStack Query
- CSS Modules
- Lucide React

API
The project uses the Campers API:
